StudyCircle - Two-page TMU student study group website

Upload index.html, groups.html, studycircle-logo.jpg and tmu-campus.jpg
to the ROOT of your GitHub Pages repository. Commit changes.

index.html = landing page
groups.html = explore study groups page
Both pages link to each other.

IMPORTANT: This is a client-side prototype. Group creation and joining are
stored in the browser only. Students on different devices cannot share
real groups until a hosted database and authentication are connected.
