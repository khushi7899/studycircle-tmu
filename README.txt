StudyCircle — two-page website (updated)

1. Extract this ZIP.
2. Upload index.html, groups.html, studycircle-logo.jpg, and tmu-campus.jpg to the root of your GitHub Pages repository.
3. Replace old versions and commit changes. Wait for Pages to deploy.

index.html: home page, including the new Explore Study Groups button below How StudyCircle works.
groups.html: search/create/join study sessions, with a TMU campus photograph in the top banner.

Note: this is a client-side prototype. Group creation is stored in the visitor's browser only; sharing groups across devices requires a backend.
